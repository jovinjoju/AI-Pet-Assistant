# AI Pet Assistant 🐾

A Python-based desktop assistant that can open applications, files, and respond to keyboard shortcuts.

## 🚀 Features
- Open desktop applications (Brave, Opera, VS Code, etc.)
- Open files from Desktop and Documents
- Supports Microsoft Store apps (Spotify, WhatsApp)
- Keyboard shortcut trigger (Ctrl + Shift + P)

## 🛠️ Tech Stack
- Python
- OS module
- Subprocess
- Webbrowser

## ▶️ How to Run

1. Clone or download this repository
2. Open terminal in project folder
3. Run:
      python main.py
4.Use shortcut: **Ctrl + Shift + P**
5. Type commands like:
   - `open brave`
   - `open spotify`
   - `open notes`
